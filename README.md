## Deskripsi Proyek

Repositori ini dibuat untuk mengumpulkan artefak pendukung pengerjaan Ujian Tengah Semester (UTS) mata kuliah Pengkodean dan Pemrograman. Repositori mencakup purwarupa HTML, dokumentasi penggunaan AI, serta dokumen pendukung pengerjaan tugas.

## Daftar Artefak

### 1. Purwarupa HTML

**File:** `voucher_entri_kas_keluar.html`

Berisi purwarupa antarmuka voucher entri kas keluar yang menggambarkan rancangan tampilan dan alur input transaksi sesuai kebutuhan tugas.

### 2. Log Prompt AI

**File:** `prompt_log.md`

Berisi dokumentasi prompt yang digunakan dalam proses pengerjaan tugas dengan bantuan kecerdasan buatan (*Artificial Intelligence/AI*).

### 3. Dokumen Jawaban UTS

Dokumen jawaban UTS memuat pembahasan sesuai instruksi tugas, termasuk spesifikasi sistem, rancangan database, dan mekanisme audit trail yang relevan.

## Tujuan

Repositori ini bertujuan untuk:
- Mendokumentasikan hasil pengerjaan tugas UTS.
- Menyediakan akses terhadap file purwarupa HTML.
- Mendokumentasikan penggunaan AI selama proses pengerjaan.
- Memudahkan dosen dalam meninjau artefak tugas.

## Catatan

Repositori ini merupakan dokumentasi tugas akademik. Purwarupa HTML menggambarkan rancangan antarmuka dan tidak dengan sendirinya membuktikan bahwa seluruh fungsi sistem telah diimplementasikan atau diuji.
